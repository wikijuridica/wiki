# Senado Dados Abertos

- nome da fonte: Dados Abertos Legislativos do Senado Federal e Congresso Nacional
- orgao: Senado Federal
- URL base: `https://legis.senado.leg.br/dadosabertos/`
- documentacao pesquisada: `https://legis.senado.leg.br/dadosabertos/api-docs/swagger-ui/index.html`
- tipo de dado: processos legislativos, comissoes, sessoes, votacoes, discursos e documentos legislativos
- formato: API publica documentada por OpenAPI/Swagger
- atualizacao: pendente de auditoria por endpoint
- licenca/termo: pendente de auditoria documental antes de uso automatico
- robots.txt: pendente de verificacao especifica antes de coleta
- limites: pendente de medicao em laboratorio
- campos disponiveis: pendente de mapeamento por endpoint
- riscos: endpoints deprecados, documentos vinculados, interpretacao de processo legislativo incompleta
- estrategia de cache: cache por endpoint, parametros e data de atualizacao
- estrategia de proveniencia: endpoint, parametros, data, codigo do processo/materia e hash do payload
- estrategia de deduplicacao: codigo oficial do processo/materia/documento
