# APIs publicas auxiliares candidatas

Estas fontes podem ajudar arquitetura, hubs geograficos, classificacoes economicas, contratos publicos ou descoberta de dados. Elas nao substituem fontes juridicas oficiais e nao estao liberadas para ingestao automatica.

## IBGE Localidades

- orgao: IBGE
- documentacao pesquisada: `https://servicodados.ibge.gov.br/api/docs/`
- uso possivel: localidades, UFs, municipios e hubs geograficos
- acesso: API publica sem cadastro individual
- risco: usar dados geograficos como base para criar paginas locais sem conteudo juridico real; isso e proibido
- status: candidata auxiliar bloqueada

## Compras Governamentais

- orgao/rede: Governo Federal / INDA
- documentacao pesquisada: `https://compras.dados.gov.br/docs/home.html`
- uso possivel: contratos, licitacoes e fornecedores em conteudo juridico-administrativo futuro
- acesso: API publica sem cadastro individual conforme documentacao consultada
- risco: dados comerciais, interpretacao fora de contexto, atualizacao e recortes temporais
- status: candidata auxiliar bloqueada

## Portal Brasileiro de Dados Abertos

- orgao: CGU / INDA
- documentacao pesquisada: `https://dados.gov.br/`
- uso possivel: descoberta de conjuntos oficiais
- observacao: algumas APIs do portal exigem token; usar apenas recursos de consulta sem cadastro quando permitido
- status: catalogo auxiliar bloqueado
