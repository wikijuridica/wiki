# STF

- nome da fonte: Pesquisa de Jurisprudencia do STF
- orgao: Supremo Tribunal Federal
- URL base: `https://portal.stf.jus.br/jurisprudencia/`
- documentacao pesquisada: `https://portal.stf.jus.br/textos/verTexto.asp?pagina=jurisprudenciaPesquisaJurisprudencia&servico=CartaServicosJurisdicionais`
- tipo de dado: pesquisa de jurisprudencia, acordaos, sumulas, decisoes monocraticas e informativos conforme base oficial
- formato: portal publico de pesquisa; API publica nao confirmada neste ciclo
- atualizacao: pendente de auditoria
- licenca/termo: pendente de auditoria antes de coleta automatica
- robots.txt: pendente de verificacao antes de coleta
- limites: pendente
- campos disponiveis: dependem da base de pesquisa e do espelho do acordao
- riscos: base selecionada, ausencia de todos os acordaos, termos de uso, carga sobre portal
- estrategia de cache: somente apos confirmar politica de acesso
- estrategia de proveniencia: URL oficial, numero/classe, data de julgamento/publicacao e data de verificacao
- estrategia de deduplicacao: identificador do processo/acordao e canonical da fonte oficial
