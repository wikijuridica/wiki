- documentacao pesquisada: `https://dadosabertos.web.stj.jus.br/`

- formato: portal publico de dados abertos e downloads/conjuntos
- atualizacao: pendente de auditoria por conjunto
- licenca/termo: termo de uso pendente de leitura completa antes de ingestao
- robots.txt: pendente de verificacao
- limites: pendente de medicao
- campos disponiveis: variam por conjunto de dados
- riscos: termo de uso, privacidade, metadados processuais, schema variavel
- estrategia de cache: por conjunto, versao, data e hash
- estrategia de proveniencia: conjunto, recurso, data de download, hash e termo vigente
- estrategia de deduplicacao: identificador oficial do recurso/processo/acordao
